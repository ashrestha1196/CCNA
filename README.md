## 🧪 Lab Repository

Each lab will have its own directory containing relevant files and documentation.

**Typical lab contents:**

- `.pkt` — Cisco Packet Tracer lab file
- `.txt` — Device configurations and command outputs
- `.png` — Network topology and verification screenshots
- `README.md` — Lab objectives, implementation steps, troubleshooting, and results

### Lab Documentation Format

Each lab README will follow a consistent structure:

1. **Lab Objective:** What I intend to accomplish.
2. **Network Topology:** Devices, connections, VLANs, and IP addressing.
3. **Configuration:** Cisco IOS commands used.
4. **Verification:** Commands and connectivity tests used to confirm operation.
5. **Troubleshooting:** Problems encountered and how they were resolved.
6. **Key Takeaways:** Concepts and practical skills learned.
